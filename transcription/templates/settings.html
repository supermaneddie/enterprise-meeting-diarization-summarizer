Speaker diarization

Optional local CPU/GPU or remote SSH processing. Requires requirements-diarization.txt and access to the selected Hugging Face model.

Remote targets use passwordless SSH and python3 on the remote host, with FFmpeg and diarization dependencies installed. Examples: remote-cpu:user@host, remote-cuda:user@host, remote-cuda:0:user@host. Voiceprints remain on the local CPU for remote targets.

Private key path on the application host, passed to ssh and scp with -i. Leave blank to use your SSH defaults. Encrypted keys must be unlocked in the application's SSH agent.

Voiceprint recognition

Local ECAPA-TDNN embeddings are compared with FAISS cosine search over each person's averaged voiceprints.

Automatically select the best matching speaker only when the cosine score is greater than or equal to this value (default: 0.4). Lower scores remain available as suggestions without assigning a name.
